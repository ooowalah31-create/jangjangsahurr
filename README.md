# jangjangsahurr

Test deploy halaman HTML sederhana ke GitHub Pages.

**Live (setelah Pages diaktifkan):** https://ooowalah31-create.github.io/jangjangsahurr/

## Isi

- `index.html` — halaman statis murni (HTML + CSS + JS, satu file, tanpa framework)

## Cara aktifkan GitHub Pages

1. Buka **Settings** di repo ini
2. Masuk ke menu **Pages**
3. Di bagian *Build and deployment*, pilih Source: **Deploy from a branch**
4. Branch: **main**, folder: **/ (root)**
5. Klik **Save**

Setelah 1-2 menit, halaman live di URL di atas.
